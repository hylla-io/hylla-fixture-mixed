# Statistics

Helpers live in [stats.py](../python/mixed_stats/stats.py) and
[clean.py](../python/mixed_stats/clean.py).

## Mean

`mean` returns the middle value of a list.

## Median

`median` returns the average of the two middle values when the count is even.

## Outliers

`drop_outliers` keeps values within a limit of the mean.
